cara download dan pake botnya:
1. <> code -> download zip
2. pas dah selesai buka codenya pake vs code atau editor code kayak gitu lah
3. bikin file .env buat token botnya (misal: TOKEN="blablabla")

kalo lu belum ada bot sendiri:
1. ke discord developer portal
2. pencet "new application"
3. terserah namanya mau gimana kek misal "bot kesehatan/lingkungan/blablabla"
4. overview -> bot buat bikin tokennya
5. dicopy trus paste di file .env lu
6. botnya lu add ke server lu (gak perlu sih karna command2nya gk harus di server buat dirun, di dm doang aja gapapa tapi kalo mau add ke server ya gapapa terserah lu dh)
7. di terminal code editor lu, ketik "python {nama file bot lu}.py" biar online soalnya kalo offline ya mana bisa lah org botnya lagi ngorok itu, bangunin biar lu bisa run command2nya
8. coba tes
